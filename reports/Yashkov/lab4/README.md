# МРЗвИС — лабораторная работа №4, вариант 10

**Дисциплина:** «Модели решения задач в интеллектуальных системах».  
**Тема:** «Многослойный персептрон для прогнозирования временного ряда: влияние размера окна и числа скрытых нейронов».  
**Результат:** отчёт в редактируемом **Word (DOCX)**. PDF в архиве нет.

## Строгое соответствие варианту

- x(k) = 2.2·cos(0.27·k) + 1.1·sin(0.62·k), k = 0...199;
- p_вар = 8, N_вар = 5; архитектура 8–5–1;
- train: k=0...139 (140 точек), test: k=140...199 (60 точек);
- train-only min/max, 132 обучающих окна и 60 тестовых (для p=8);
- скрытый слой Sigmoid, выход Linear, online backprop + перемешивание каждого эпохи;
- `Es = mean((pred_norm - target_norm)**2)`, порог `1e-4`, максимум `20 000` эпох;
- скорость обучения `0.12`; начальные веса `uniform(-0.1, 0.1)`;
- seed: 10, 20, 30, 40, 50 (отдельные модели для каждого запуска);
- изучены `p={2,4,8,16}`, `N={1,2,5,10}` — всего 35 самостоятельных запусков;
- дополнительный эксперимент с шумом (ещё 5 запусков), рекурсивный прогноз на 30 шагов;
- результаты в исходной шкале — MAE, RMSE и sMAPE (ряд пересекает ноль).

## Быстрая проверка и запуск

```bash
cd lab_4/src
python -m pip install -r requirements.txt
python checks.py
python render_plots.py
python demo.py
```

В `demo.py` введите `140` для тестового окна, `24` для обучающего или восемь чисел через пробел для собственного окна; `q` — завершение.

Чтобы **заново выполнить все эксперименты** с чистым NumPy (35 основных + 5 шумовых, до 20 000 эпох каждый):

```bash
cd lab_4/src
python run_full_experiment.py
```

Долгий полный запуск не нужен, чтобы открыть Word или проверить полученные результаты: все сохранённые числа и 35 наборов весов присутствуют в `src/results/`.

## Обоснование технических решений

Считаем тестовый одношаговый прогноз по реальной наблюдаемой прошлой истории, включая ранее известные тестовые наблюдения. Это нормальный one-step режим: целевые тестовые значения не входят в обучение. Для рекурсивного прогноза применяется другой, **строго авторегрессионный** режим: начиная с k=140 в окно подставляются только предшествующие предсказания.

Для сравнения выбран p,N с наименьшей **средней тестовой MAE за пять seed**, а рекурсивный график построен для лучшего seed внутри выбранной конфигурации. Использование тестовой выборки для подбора параметров может оптимистично смещать оценку; для производственной задачи понадобился бы отдельный validation-участок. В учебном эксперименте такой выбор следует пункту методички.

Чистый численный результат: p=16,N=5 — лучшая средняя тестовая MAE среди проверенных конфигураций; p=2 ни в одном из пяти запусков не достигло порога за 20 000 эпох; ошибка рекурсивного прогноза не превысила 5% полного размаха за 30 шагов. Полная точность и условия приведены в DOCX/metrics.json.
