# МРЗвИС — лабораторная работа №4, вариант №5

**Дисциплина:** «Модели решения задач в интеллектуальных системах».  
**Тема:** «Многослойный персептрон для прогнозирования временного ряда: влияние размера окна и числа скрытых нейронов».

## Вариант и методика

- Формула: `x(k) = 2.5*cos(0.35*k) + 1.2*sin(0.80*k)`, `k=0...199`.
- `p_варианта=7`, `N_варианта=6`: базовый MLP `7–6–1`.
- `train = k 0...139` (140 точек), `test = k 140...199` (60 точек).
- Нормализация `Min-Max` **только по train**, для `p=7`: 133 train-примера, 60 test-примеров.
- Скрытый слой — sigmoid, выход линейный, loss на одном примере — `0.5 * (prediction-target)**2`.
- Online backprop: обновление всех весов после каждого обучающего примера; перемешивание каждой эпохи.
- Остановка после эпохи при `Es = mean((prediction_norm-target_norm)**2) <= 1e-4` либо 20 000 эпох.
- Learning rate `0.12`, начальные параметры `U(-0.1,0.1)`, seed: 10, 20, 30, 40, 50.
- Варьируем размер окна `p in {2,4,7,14}` при N=6, затем нейроны `N in {1,2,6,12}` при p=7: **35 уникальных обучений**.
- Дополнительно 5 запусков с шумом на входах train; одношаговые MAE/RMSE/sMAPE и рекурсивный 30-шаговый прогноз.

## Запуск

Для проверки уже сохранённых моделей без длительного обучения:

```bash
cd lab_4/src
python -m pip install -r requirements.txt
python checks.py
python render_plots.py
python demo.py
```

Введите `140` или `157` для тестовых окон, `24` для обучающего или семь значений через пробел для собственного окна. `q` — выход.

Полный пересчёт 35 + 5 запусков (NumPy, без ML-фреймворков):

```bash
cd lab_4/src
python run_full_experiment.py
```

**Важно:** полное повторное обучение на CPU может занимать значительное время (особенно `p=2`, где задан лимит 20 000 эпох). Все метрики и сохранённые веса уже приложены; повторять обучение для проверки отчёта необязательно.

## Основные фактические результаты

- Базовая модель `p=7,N=6,seed=10`: критерий остановки достигнут за 84 эпохи; test MAE = 0.062936.
- Для `p=2,N=6` все пять запусков остановлены по лимиту 20 000 эпох без достижения `Ee`.
- Среди семи вариантов лучшая **средняя** тестовая MAE у `p=7,N=12`: 0.060179 (5 запусков).
- Рекурсивный прогноз взят у лучшего seed 30 для `p=7,N=12`; первое превышение 5% полного размаха произошло на **4-м шаге**.
- Шум `sigma=0.02` на входах ухудшил тестовую MAE для этого эксперимента; детали в таблице отчёта.

## Обязательная рукописная часть

По методичке требуются **две фотографии фактически рукописных листов**: блок-схема обработки и полный пример forward/backward для `3–2–1`, `V=5`. В Word приведены готовые правильные расчёты и макет блок-схемы, но они **не заменяют фотографии**. См. отдельную инструкцию в `doc/`.

При оформлении титула сохранена разметка присланного образца (ФИО и группа из образца); проверьте данные исполнителя перед сдачей.

## Оговорка об оценке

Методичка просит выбрать лучшую конфигурацию по тестовой MAE. Это сделано. Для реальных задач такие решения следует принимать по отдельной validation-выборке, не используя test для подбора гиперпараметров. Здесь следуем учебной постановке.
