# МРЗвИС — лабораторная работа №1, вариант 6

## Состав
- `doc/lab_1.docx` — редактируемый отчёт Word, без PDF.
- `src/main.py` — запускаемый код на NumPy (для работ 2–4 также Matplotlib).
- `src/xor_engine.py` — реализация модели с online backpropagation.
- `src/requirements.txt` — минимальные зависимости.
- `src/results/` — таблицы метрик и настоящие графики экспериментов.
- `src/data_variant_6.csv` — исходные данные варианта 6.

## Запуск
```bash
cd src
python -m pip install -r requirements.txt
python main.py
python main.py --quick
python main.py --interactive
```
Без `--quick` выполняется полный предел до 20 000 эпох. Результаты перезаписываются в `src/results/latest_run.json`. Режим `--quick` используется только для короткой проверки запуска и **не соответствует полным таблицам отчёта**.

## Оформление титула
За основу взята первая страница присланного отчёта одногруппника в исходном оформлении. Сохранены данные автора и проверяющего из шаблона (`Суховило В. С.` / `Никитин С. К.`), поскольку пользователь просил не изменять титульную страницу. В №2–4 номер и название работы адаптированы к содержанию. **Проверьте ФИО перед сдачей** — эти данные могут быть чужими.

## Методический нюанс
Сигмоида ограничена (0, 1). Поэтому MSE непосредственно по числовым целям −9/6 не может дать малую ошибку. В отчётах исходная MSE и обучаемые нормализованные модели показаны отдельно; неподтверждённые значения сходимости не объявляются достигнутыми.
